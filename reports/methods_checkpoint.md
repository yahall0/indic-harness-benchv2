# Methods and limitations at the preparation checkpoint

All 106 original definitions were audited. The study selects 40 lightweight tasks, five from each of eight original families, before observing model outcomes. Tasks 008 and 013 are excluded for unavailable image capabilities; 64 others are deferred. Task 025 has an unsatisfiable original oracle check and was replaced by task 027 before freeze. No old Indic attempt results were used.

All selected original oracles passed AI-constructed positive, missing-output and meaningful incorrect-output checks in restricted Docker. Forbidden fixture edits were detected separately where fixtures exist; task 007's round-one leak hook was tested negatively. Original oracle code and scoring remain unchanged. Oracle validation does not prove that every semantic defect will be detected; some original graders use keyword coverage or permissive schema checks.

Infrastructure differences are private-build LF normalization of decodable text fixtures to match source oracle hashes, a grader-only task 012 directory layout correction, and an isolated task 022 HTTP service with its original pagination and per-page transient error behavior. The task 022 loopback proxy preserves the original oracle's URL contract. Trusted helper logs are exported outside agent storage and compared with its submitted access log. Task 017 retains the original runner behavior, which does not call its setup/teardown functions.

All OpenClaw execution and descendants stay inside non-root Docker containers with read-only roots, no host mounts or Docker control interfaces, dropped capabilities, no-new-privileges, seccomp and resource caps. Graders have no network or credentials and execute after the agent stops. Keys are encrypted with current-user Windows DPAPI and passed only to the restricted relay over stdin. Docker reduces the disk-loss risk but is not an absolute guarantee against kernel/container vulnerabilities.

Four real key probes succeeded with GPT-OSS-20B: 268 input tokens and 64 output tokens in total. These probes are not research runs. Integration and rotation tests use simulated inference, including actual OpenClaw tool execution, multi-round state, quota progression and durable save/reopen. No 120-run evaluation has started.

The planned conditions use one model and one harness, temperature 0, medium reasoning, whole-attempt timeout up to 600 seconds, at most 30 physical inference requests, 100,000 input tokens and 16,000 output tokens. The relay conservatively reserves a UTF-8 byte bound plus framing allowance before each request, then reclaims unused allowance when provider usage is known. Ambiguous retries retain their reservations. Conservative preflight can stop a run early and can differ by script; disclose this limitation rather than claiming identical realized compute or causal tokenizer effects.

Primary outcomes are original oracle scores and full completion, with added integrity violations reported separately. SQLite accounting and bounded inference traces preserve requests, slots, retries, latency and available provider token usage. Metrics exports retain absent measurements as null. First-context token ratios include system/tool overhead. Tool-schema errors and compaction event counts remain unavailable unless explicitly observable; no paid process grader is used.

Analysis compares English minus Hindi and English minus Hinglish, using complete matched triplets, category breakdowns and task-level paired bootstrap intervals. Infrastructure failures, quotas and interrupted attempts are listed separately, with incomplete triplets visible. The 40-task, one-attempt study is exploratory; it cannot establish broad Indian-language effects, isolate tokenizer causes or promise statistical significance.

Translation correction remains pending. The earlier Hindi drafts used a mechanical Roman-to-Devanagari mapping and need natural-language review. Task 027 needs two new translations. The same English prose-output contract applies to all three conditions. Translation and review are AI work, not independent human validation. The dataset must remain unreleased and unfrozen until this review and final gates pass.
