root_cause.json requirements:
- Top-level object में ये fields हों: incident_id, root_cause_service, root_cause_change_id, confidence, affected_services, evidence, excluded_red_herrings, recommended_next_steps.

- excluded_red_herrings में misleading signals के नाम और यह समझाएँ कि वे primary cause क्यों नहीं हैं.

triage_notes.md requirements:
- User impact से root cause तक dependency path summarize करें.
- कम-से-कम तीन fixture files के paths cite करें.
- तुरंत mitigation और verification steps include करें.
- Inferences को directly observed facts से स्पष्ट रूप से अलग mark करें.
